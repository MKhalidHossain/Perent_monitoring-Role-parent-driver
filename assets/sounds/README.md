# Sound Files for Splash Screen

This directory contains placeholder sound files for the splash screen.

## Files:
- `splash_sound_1.mp3` - First splash sound
- `splash_sound_2.mp3` - Second splash sound  
- `splash_sound_3.mp3` - Third splash sound

## Instructions:
Replace these placeholder files with actual MP3 audio files for the splash screen sounds. The app will play these 3 sounds in sequence when the splash screen loads.

## Navigation Flow:
1. Splash Screen (1.5 seconds with 3 sounds) → 
2. Onboarding Screen → 
3. Select User Type Screen → 
4. Signup Screen
